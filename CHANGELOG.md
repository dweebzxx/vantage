## [0.1.0] - 2026-10-15

### Added

- First recorded version of the vantage application: a local single-player prototype through M3 code, with player movement, hitscan and projectile weapons with weapon switching, a thrown grenade with radius falloff damage, a view-only combat HUD, and damage applied to dev target dummies only.
- `tests/manual/checklist-m3.md`, the M3 local-combat manual checklist for the Human to run in the Godot editor.

### Documentation

- The core documents adopted the new YAML header and per-document `MAJOR.MINOR.PATCH` versions on 2026-10-15; each document's version is in its own header.
